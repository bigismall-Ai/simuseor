#议题裁决
1900px 图标分支与「冻结只改 3 处」矛盾全断点横版字标：占位期文字 / 冻结后同一元素换 SVG 字标，≤900 只隐藏中文副行；30×30 图标仅用于 favicon 与未来紧凑场景，不设互斥 CSS 分支
2加载 Inter 是否会改变正文观感M0 只落 Barlow 一个 woff2；Inter 的 @font-face 保留为预留声明但不放 woff2 文件（缺文件时被忽略，正文继续走系统回退栈，零渲染回归）。将来统一到 Inter 须单独排期 + 截图回归
3组件 scoped 30 处审计盲区按全量口径写入手册补遗，Phase 1 / 2 双文档冻结不动：字重 26 处、--faint 文本 39 处并入 M1 补充批次；cover-plate 的 3 处圆角定性为「适用域外」（封面铭牌是独立图形子系统），不收敛、不登记为第三类例外；其余 1 处并入 M1
4品牌层六枚 --brand-* 深色映射认可不改：固定 HEX + 语义别名做深色反白映射，符合「反白靠双份 SVG 资产，不是 CSS 取色」；零覆盖校验已 PASS
5深色主按钮 hover --primary-hover 4.47:1 不达 AA采纳方案 A：button.primary:hover 保持 background:var(--primary) + --on-primary 白字，仅以 border-color:var(--accent) 作 1px 装饰描边（3.15:1 ≥ 3:1）。不改任何 token 值、不新增第 16 项冲突；并入 M1-d 与脚本 1.11，双主题维持 6.29:1

仍需主理人拍板的两件事：① LOGO 冻结（先裁「负形 D / 正形 L1」路线，再定字形、叶数、横竖版）—— M3 唯一门禁； ② 将来是否把正文统一到 Inter（须单独排期 + 截图回归）。 cover-plate 3 处圆角已按裁决 3 定性为「适用域外」，不再是待拍板项。M0–M2 不需要等这两件事。

附录 B · 三条教训

  1. 换字体必须跨骨架体系并排看图，不能只换同大类相近款。
  2. 用户给参考链接要真的去读 CSS，别凭「编辑式排版」脑补。
  3. 「藏在 M 里」要求月桂顶端明显低于 M 肩线；Barlow 的浅内腔决定了必须走笔画镂空而非贴图。
