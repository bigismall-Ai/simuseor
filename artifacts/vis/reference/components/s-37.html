COMPONENTS 组件 · 本章共 12 节

app-workflow-card 的四态：普通 / hover / 缺依赖 / 无法解析。 状态由 state() 决定：format==='broken' → 无法解析；format==='api' → API 格式；缺依赖数 > 0 → 缺依赖；否则 → 普通。 下方为静态等价物，几何与配色取自组件 scoped 样式。

封面左上角不再放主模型厂牌：一条工作流经常同时串起多个家族的模型 （例如 WAN 主模型 + Qwen 文本编码器 + LTX 放大），标一个厂牌会误导。 这里改放工作流类型，词表与后端 weight_class.TASK_LABELS 对齐：文生图 · 图生图 · 文生视频 · 图生视频 ·图文生视频 · 文本生成 · 图像理解 · 语音合成 ·语音识别 · 向量嵌入 · LoRA 风格 · 图像放大 ·ControlNet 控制 · 未标注。工作流卡实际只会落到前 6 类与「未标注」。
