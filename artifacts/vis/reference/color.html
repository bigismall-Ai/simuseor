COLOR色彩

VIS §3.1 裁决 A：分层双轨。品牌层（纸墨）不进高频 UI；产品层（zinc 中性 + 靛紫）供全站界面。 §3.7.5 的 token 分层把产品层再拆成三层：primitive（原始值）→ semantic（用途语义）→ component（组件槽位）。明暗只发生在 semantic 层，primitive 一套共用。 v2.6 补齐两处缺口：① 产品里本就存在的模型卡美术色域（家族色 / 任务色 37 组四槽色）此前 无文档（§s-16）；② 全站 6 类渐变此前既无 token 也无口径，本轮收口为 4 级 12 枚 --grad-*（§s-19）。

怎么读本页：每枚色块下方左值 = 浅色主题，右值（靛紫）= 深色主题。两值相同时只显示一个。 切换右上角「切换主题」可看整页翻转。
四张表分工：§s-11～§s-15 是色板（有什么值）→ §s-16 是模型卡美术色域 （家族 / 任务色有什么值）→ §s-17 是色域约束总表（什么不许做，13 条可判定）→ §s-18 是国际色彩锚点（Pantone / 红点给我们的外部标尺）→ §s-19 是渐变层（渐变怎么用，9 条硬约束）。

模型卡美术色域 —— 家族色 / 任务色（--plate-*）

这一层不进 UI token，但它是产品里唯一大面积出彩色的地方：模型卡的封面底、铭牌、 构图纹样全部取自它。纪律只有两条 —— ① 每个家族 / 任务给四槽（底 / 字 / 强调 / 纹样）； ② 明暗换整套色，不翻色板（浅底在深色页面上会整块发亮）。 唯一出处 web/src/app/core/model-tone.ts，封面组件也走这一份，改颜色只改这里一处。

家族色 / 任务色的组数以本节为唯一口径源（家族色 25 组 / 任务色 12 组 / 中性 1 组）。 其他页面（布局页的铭牌样张等）可做节选，但必须标明「节选」并回链本节，不得另立数字。 数量由本脚本从 model-tone.ts 现场统计，改家族即改数字，不会漂。

下面色块的四段色带就是该家族自己的 ramp（底 → 字 → 强调 → 纹样）， 左侧值 = 浅色主题、右侧值 = 深色主题（按右上角「切换主题」看整页翻转）。

槽位变量浅色实测域深色实测域职责
底--plate-bg L* 93–96 · C* 1–12 L* 10–14 · C* 2–18 整块封面底 / 分类胶囊底
字--plate-ink L* 35–48 · C* 3–50 L* 71–84 · C* 4–42 铭牌正文、发布方、规格行

读法：家族底永远是一张纸（L* 93–96、 彩度 C* ≤ 12），字与强调往下压两级（明度差 55–75），纹样是唯一不随主题变的槽 （明暗共用，靠 opacity 压深）—— 这就是「一屏卡片不同色但成一套」的全部机关。

色域约束总表（可判定）

「克制」不是形容词。下面每一条都能被量出来：要么数面积、要么算比值、要么查色相与彩度。 区间里的数字全部来自实测（家族色 25 组 / 任务色 12 组 / 明暗两套， 脚本 artifacts/vis/vis-color-domain.py），不是经验值。

国际色彩锚点（Pantone / Red Dot）

色彩范围要有外部坐标，否则「合规」只是自说自话。下表是国际设计体系里可查证的颜色锚点， 用途有二：① 给我们的色域定标尺（什么算「纸感」、什么算「冷灰」、什么算「高彩度」）； ② 给印刷物料定打样目标。 但 Pantone 色号不能直接搬进 UI —— 专色的 sRGB 值只是近似，屏幕与印刷必然有色差， 最终以实物色卡打样为准。

渐变层（--grad-*）〔本轮新增〕

VIS §3.4 只禁了「大面积渐变铺底」，但产品里本来就有 6 类渐变：蝉形 82 条面片微渐变、 favicon 5 档色带、卡片信息区遮罩、封面照片 scrim、封面 5 构图纹理、家族铭牌底 —— 它们此前既没有 token 也没有口径，全是就地硬编码的 rgba 串，谁改谁都漂。 本轮把渐变收口成 4 级 12 枚 --grad-* token （vis-tokens.css §4 与 vis.css 同名同值），并补齐可判定约束。
