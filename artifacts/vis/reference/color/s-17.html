色域约束总表（可判定）

COLOR 色彩 · 本章共 9 节

「克制」不是形容词。下面每一条都能被量出来：要么数面积、要么算比值、要么查色相与彩度。区间里的数字全部来自实测（家族色 25 组 / 任务色 12 组 / 明暗两套， 脚本 artifacts/vis/vis-color-domain.py），不是经验值。

#维度约束（可判定）依据 / 实测
1面积配额（产品 UI 单屏）中性表面 + 文字 ≥85%；边框 / 结构线 ~10%；交互强调色 ≤5%；实心靛紫块 ≤2 处 / 屏；语义色 ≤3%VIS §3.4
2面积配额（品牌展示面）暖纸底 ≥75%；线 / 装饰 ≤5%；墨黑字标与文字 ≤20%；语义色 0VIS §3.4
3交互色域靛紫只允许 50 / 100 / 300 / 600 / 700 五档；400 / 500 档禁作前景（白字 2.98 / 4.47:1 双双 FAIL）；深色 --primary 不翻（仍 600）实算见 §s-15
4家族底域L* ∈ [93, 96]、彩度 C* ≤ 12 —— 底永远是低彩度纸感；不得出现高彩度家族底实测 25 族
5家族字域ink on bg≥4.5:1；strong on bg ≥6:1实测最低 4.24:1（lumina）—— 唯一未达标项，该家族 ink 不得承载小字，或把 ink 提到 ≥4.5:1
6家族纹样域mark永不承载文本；只作纹样 / 图形 / 渐变端点实测 mark/bg 仅 1.68–2.81:1
7任务色域12 类固定映射，不得新增第 13 类；认不出家族也不许把任务色当家族色实测最低 4.56:1 全部达标
8中性兜底域家族、任务都认不出 → 中性灰 #f2f1ed / #232321；不得猜色model-tone.ts:99-100
9语义色域success / warning / danger 三通道固定；500 档禁作前景；深色 soft 底用半透明（rgb(… / .12)）而非浅实色VIS §3.3 / §3.4
10暖冷中性隔离品牌暖纸 #f8f6f1 与 UI 冷白 #ffffff不得混用于同一文本块；品牌层不设交互色、不引 --accentVIS §3.2
11明暗映射保持相对层级而非逐一取反：表面四层一一对应、文字四档一一对应、深色强线更亮、文字型强调翻明度、填充型不翻；禁第二套主题开关、禁 filter:invert()VIS §3.6
12色觉安全红 / 绿状态必须双编码（颜色 + 图标或文字），不得单靠色相；实心靛紫作白字填充时白字对比度须 ≥4.5:1WCAG 2.2 §1.4.1
13渐变域色相位移 / 明度跨度 / 角度白名单 / 面积上限 / 遮罩 alpha 下限 —— 共 9 条硬约束，见 §s-19VIS §3.8
14站点底纹域站点底 = 中性底 + 一束光（色场）+ 中性纸纹（无彩）；底纹不计入「中性表面 ≥85%」配额（它铺在页面底，不是表面）；禁把标识铺成底纹；深色主题换噪声图而非反相；侧栏用透明渐变（左缘实面、右缘化到透明），不加实色面板、不加投影VIS §3.10（v2.7 裁决）
