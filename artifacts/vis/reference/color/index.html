COLOR色彩

VIS §3.1 裁决 A：分层双轨。品牌层（纸墨）不进高频 UI；产品层（zinc 中性 + 靛紫）供全站界面。 §3.7.5 的 token 分层把产品层再拆成三层：primitive（原始值）→ semantic（用途语义）→component（组件槽位）。明暗只发生在 semantic 层，primitive 一套共用。v2.6 补齐两处缺口：① 产品里本就存在的模型卡美术色域（家族色 / 任务色 37 组四槽色）此前 无文档（§s-16）；② 全站 6 类渐变此前既无 token 也无口径，本轮收口为 4 级 12 枚--grad-*（§s-19）。

怎么读本页：每枚色块下方左值 = 浅色主题，右值（靛紫）= 深色主题。两值相同时只显示一个。 切换右上角「切换主题」可看整页翻转。
四张表分工：§s-11～§s-15 是色板（有什么值）→ §s-16 是模型卡美术色域 （家族 / 任务色有什么值）→ §s-17 是色域约束总表（什么不许做，13 条可判定）→ §s-18 是国际色彩锚点（Pantone / 红点给我们的外部标尺）→ §s-19 是渐变层（渐变怎么用，9 条硬约束）。
