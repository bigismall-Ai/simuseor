渐变层（--grad-*）〔本轮新增〕

COLOR 色彩 · 本章共 9 节

VIS §3.4 只禁了「大面积渐变铺底」，但产品里本来就有 6 类渐变：蝉形 82 条面片微渐变、 favicon 5 档色带、卡片信息区遮罩、封面照片 scrim、封面 5 构图纹理、家族铭牌底 —— 它们此前既没有 token 也没有口径，全是就地硬编码的 rgba 串，谁改谁都漂。 本轮把渐变收口成 4 级 12 枚 --grad-* token （vis-tokens.css §4 与 vis.css 同名同值），并补齐可判定约束。

分级：每级渐变各管什么

级名称现状出处规则
G0品牌色带蝉形 82 条面片渐变 / favicon 5 档品红 → 橙暖弧，跨色相是刻意的；每面片独立成条，禁止改成一条全局贯穿渐变（会压平面片差异、拼块感消失）
G1家族色渐变家族铭牌底（model-tone 三槽派生）同色相、只走明度阶：Δh ≤ 10°，不引入第二个色相
G2遮罩 scrim卡片信息区遮罩 / 封面照片 scrim文字压照片的唯一手段；alpha 下限 0.57（见下表）
G3构图纹理封面 5 变体中的斜纹 / 点阵 / 柔光只出家族色派生，不引入独立色；深色主题浓度自动下调
G4交互渐变本轮新增（主按钮 / 选中态）受限：面积 ≤2 处/屏，两端白字都 ≥4.5:1，深浅各一套
G5站点底纹站点整体背景（§3.10 · v2.7 裁决）纯中性底 + 一束光（色场）+ 中性纸纹；定稿 v2 单束柔光，色场 70% / 纸纹 60%；底纹不计入「中性表面 ≥85%」配额；禁标识平铺；深色换噪声图不反相。渐变共 6 个变体（取值表见 VIS §3.10；对比实验稿已退役删除）

渐变硬约束（9 条）

#约束判定口径依据
1色相位移上限G1 家族渐变 Δh ≤ 10°；G2 遮罩为中性色不适用；G0 品牌色带是唯一豁免（跨暖弧是刻意的）实测 flux 7.2° / qwen 9.3°
2明度跨度G1 走明度阶 ΔL* 18–70；G0 面片级微渐变 ΔL* ≤ 6（×0.97→1.03）蝉形 82 条渐变口径
3彩度上限任一端点彩度不得高于另一端的 1.04 倍；禁止用高彩度端点承载白字蝉形 ×1.04→1.00
4角度白名单只准 90° / 135° / 160° / 162° / to top / to bottom / -58° / radial；禁 0°/180° 平铺彩虹现行实现盘点
5面积上限G4 交互渐变 ≤2 处/屏；G1 家族渐变 ≤卡面 40%；禁大面积铺底（VIS §3.4）VIS §3.4 + 本轮收紧
6文字禁则禁给文字上渐变；文字压在渐变上时，渐变两端都要与文字色 ≥4.5:1WCAG 2.2 §1.4.3
7遮罩 alpha照片卡白字：遮罩 alpha ≥ 0.57（对最亮照片成立）；现行 0.45 在纯白照片上只有 3.12:1实算见下表
8明暗双版渐变必须明暗各一套，禁 filter:invert() 取反；G1/G2/G3 由 --plate-* 派生自动跟随VIS §3.6
9印刷口径渐变在印刷里是网点过渡，色域外自动陷色；品牌物料须给两端专色 + 打样，不许拿渐变截图上机§s-18 锚点
