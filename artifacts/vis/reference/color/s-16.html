模型卡美术色域 —— 家族色 / 任务色（--plate-*）

COLOR 色彩 · 本章共 9 节

这一层不进 UI token，但它是产品里唯一大面积出彩色的地方：模型卡的封面底、铭牌、 构图纹样全部取自它。纪律只有两条 —— ① 每个家族 / 任务给四槽（底 / 字 / 强调 / 纹样）； ② 明暗换整套色，不翻色板（浅底在深色页面上会整块发亮）。 唯一出处 web/src/app/core/model-tone.ts，封面组件也走这一份，改颜色只改这里一处。

家族色 / 任务色的组数以本节为唯一口径源（家族色 25 组 / 任务色 12 组 / 中性 1 组）。 其他页面（布局页的铭牌样张等）可做节选，但必须标明「节选」并回链本节，不得另立数字。 数量由本脚本从 model-tone.ts 现场统计，改家族即改数字，不会漂。

下面色块的四段色带就是该家族自己的 ramp（底 → 字 → 强调 → 纹样）， 左侧值 = 浅色主题、右侧值 = 深色主题（按右上角「切换主题」看整页翻转）。

槽位变量浅色实测域深色实测域职责
底--plate-bgL* 93–96 · C* 1–12L* 10–14 · C* 2–18整块封面底 / 分类胶囊底
字--plate-inkL* 35–48 · C* 3–50L* 71–84 · C* 4–42铭牌正文、发布方、规格行
强调--plate-strongL* 20–35 · C* 3–55L* 86–92 · C* 3–32家族码、参数行、芯片文字
纹样--plate-markL* 60–76 · C* 4–45L* 60–76 · C* 4–45构图纹样、芯片底、渐变端点

读法：家族底永远是一张纸（L* 93–96、 彩度 C* ≤ 12），字与强调往下压两级（明度差 55–75），纹样是唯一不随主题变的槽 （明暗共用，靠 opacity 压深）—— 这就是「一屏卡片不同色但成一套」的全部机关。
