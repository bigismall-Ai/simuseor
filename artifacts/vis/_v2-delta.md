## 2. §1.1 命名与定位 —— 全文改写（已起草）

### 2.1 v1.0 原文的问题

v1.0 §1.1 第二条写的是：

> 定位：**AIGC 创作工作台 / 模型社区 / 内容创作平台**。工作流是最大资产，「查 + 下载」是基础建设。

**这已被用户 2026-11-13 拍板推翻。** 新定位是「**剧集（电影）AI 导演台**」。

### 2.2 v2.0 起草正文（可直接粘贴）

```md
### 1.1 命名与定位

- 品牌名 **`SiMuseor`**（内嵌 `muse` / 缪斯），唯一书写形式，大小写固定 `S-i-M-u-s-e-o-r`。禁 `SIMUSEOR` / `Simuseor` / `Si Museor`。中文名 **司梦**（司 = 掌管、主导；梦 = 梦境、想象）。
- 定位：**剧集（电影）AI 导演台**。核心工作流是 **剧本 → 分镜 → 镜头 → 成片** —— 把想象变成成片。工作流是最大资产，「查 + 下载」是基础建设。
- **标识由两层构成**：**字标 `SiMuseor` 是主视觉**，**蝉形是辅助图形**（低多边形几何分面，品红→橙）。两者共存构成组合标；蝉形单独出现当前**仅限 favicon**。
- 对外禁用作品牌自称：`Model Downloader`、`下载器`、`Local Studio`、旧 `MD` 方块。仓库名 `model-downloader` 仅作工程标识。
- **保留不动**：导航「下载任务」、路由 `/downloads`、存储键 `md-*`、测试标题 `test.describe('Model Downloader Web UI')`。
```

> 📌 **语义注记**：蝉形与品牌名是**两个独立命题**。用户原话：「我们是 SiMuseor 司梦，不是蝉」—— 蝉形不是「梦」的图解，它承载的是**蜕变 / 再生 / 正在发生**（见 §3 品牌语义专节，以及柏拉图《斐德若》里「蝉是缪斯的信使」这一古典依据）。

**v2.0 改法**：保留 7 个子节编号不动，在 §2 开头**插入 §2.0「辅助图形层（蝉形）」**，并把 2.1/2.3 的相关条目改写。**不重排既有编号** —— 全文有大量交叉引用，重排风险高。

### 3.1 §2.0 起草正文（结构 + 关键数字）

```md
### 2.0 辅助图形层 —— 蝉形〔新〕

> 〔现〕用户已交付三帧成品 JPG（1536×1536 白底）。本节定义它如何进入标识体系。
> 全部实测数字见 `_cicada-measurements.md`（唯一基准）。

**两层关系**：字标 = 主视觉；蝉形 = 辅助图形。**不互相取代。**

#### 2.0.1 三帧与分工

| 帧 | 形态 | 用途 | 本版接入 |
|---|---|---|---|
| **MIN** | 竖直收拢 | 展翅动画起始帧（未来） | ❌ 资产库储备 |
| **MID** | 半展 | 展翅动画中间帧（未来） | ❌ 资产库储备 |
| **MAX** | 全展 · 横向双翅 | **favicon + 侧栏组合标** | ✅ 唯一接入帧 |

MIN 永久否决作为静态组合标：实测 19.7px 高时**仅 9px 宽**，读作竖直色条。

#### 2.0.2 组合标（侧栏品牌位）

| 项 | 值 |
|---|---|
| 蝉形 | **MAX 56×26px**（等比，宽高比 2.1693） |
| 图–字间距 | **10px**（复用 `.brand` 既有 `gap`） |
| 字标 | Barlow Condensed Regular 400 / 20px / cap-height **14.00px** / 墨迹宽 **62.92px** |
| 视觉总宽 | **128.9px**（侧栏品牌位可用宽 200px，余量 71.1px） |
| 对齐 | 蝉形**腹部尖端 ≡ 字标 baseline**（地脚线对齐） |
| 排布 | 蝉形在左、字标在右（横版） |

**辅助地位的量化保证**：蝉形宽 **56px < 字标墨迹宽 62.92px**（余量 11.0%）。**蝉形上调至 ≥63px 即击穿** → 必须同步下调。

#### 2.0.3 三层尺寸策略

接缝线（白色发丝）在源图里原生宽 1px（相对 1397px 主体），渲染后 **64px → 0.046px / 256px → 0.183px / 1024px → 0.733px**。

| 层 | 区间 | 处置 |
|---|---|---|
| **L1** | ≥1024px | 保留原生发丝接缝 |
| **L2** | 64–1024px | 接缝必然消失 → 改由**面片色差**承载；需线感须**另出加粗接缝资产** |
| **L3** | 16–64px | **独立重画简化版**（4–6 大面片 + 深紫描边 + 间隙 ≥1px），**不缩放 MAX 帧** |

#### 2.0.4 favicon

MAX 帧 + **fill**（长边铺满方画布）—— 16px 下唯一保住「横向双翅 + 中央身体」可辨性的方案。**必须自带底色**。产物：`favicon.svg` + `favicon.ico`（16/32/48）+ 各尺寸 PNG。

#### 2.0.5 深色主题

**禁止**「白线换深线」（`#2a0a2e` on `#15151a` = 1.02:1，完全不可见）。三选一：① 暗部提亮到 ≥3:1 ② 暗剪影 + 白骨架线 ③ 单色化剪影 + 反白线。

#### 2.0.6 禁用

提取蝉形做纹样 / 平铺 / 水印 / loading / 家族色编码；对称蝉形环 / 盾形徽章 / 放射星芒；非等比拉伸；单独出现在 favicon 以外的产品位。
```

### 3.5 §2.5 占位规范 —— 补蝉形落位

v1.0 §2.5 的 HTML/CSS 草案**已过时**（`.brand-wordmark` 挂在 `.brand` 下，但 `.brand` 是行向 flex，「副行」排不成第二行）。v2.0 补一条**蝉形落位裁决**（由 `_phase2-cicada.md` 提供最终口径）：

- 蝉形 `alt="" aria-hidden="true"`，可访问名只由字标 `aria-label="SiMuseor"` 承载
- 窄屏 `styles.css:1616` 的 `.brand-text{display:none}` 会连字标一起隐藏 —— v2.0 需给出口径

## 4. §3 色彩系统 —— §3.1 分层双轨增补

v1.0 §3.1「分层双轨 = 品牌层 `--brand-*` 六枚 + UI 层原样保留」。v2.0 增补一条：

> **蝉形色阶不进 token 层。** 蝉形是**资产**，不是可换肤的界面色 —— 其色阶 `#4b0350`（plum，暗部点缀色占主体 5.8%）→ `#f04c3e`（暖红）**作为图像的一部分冻结在 SVG 里**。深色主题走**独立资产**，不走 token 覆盖。

理由：蝉形是插画型资产，用 token 换色会破坏其低多边形的面片关系。
