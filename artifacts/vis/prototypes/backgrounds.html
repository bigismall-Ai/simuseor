BG站点底纹 · 渐变 × 纸纹 变体集

站点整体底纹只做「渐变 + 纸纹」这一种组合：纯色、单独渐变、单独纸纹都出局 —— 纯色没有方向，单独渐变颜色压过内容，单独纸纹干净但没方向。 下面是渐变本身的六种变体，每一种之上都叠同一张纸纹，用两个滑杆独立调「色场」与「纸纹」。

2026-11-21 定稿：v2 单束柔光，色场 70%、纸纹 60% —— 已按 VIS §3.10 落入产品（--grad-site-wash / --grad-site-glow / --texture-site-paper，web/src/styles.css 的 body；VIS 手册站同款）。 本页滑杆的当前值 = 产品当前值（色场 70 / 纸纹 60），可直接与线上对照； 滑到 100% 是设计上限，不是现状。 另：「黑白线稿全铺」已否（观感：蝉形一旦铺成底纹，辅助图形就降级成装饰纹样，且撞 §2.0.6 / §2.4⑤）。

各 α0.048–0.066		radial 顶部提亮
α0.030		整页一道左→右的彩纸色带，识别度最强；代价是横向明显分割，与「克制收敛」的调性最不合

共同纪律（六变体一律适用）：色场峰值 α ≤ 0.07（底仍读作中性灰，不是品牌色）；纸纹中性无彩， 浅底 multiply / 深底 screen；底纹不计入「中性表面 + 文字 ≥85%」配额（它铺在页面底，不是表面）； 禁把标识铺成底纹；导出物 / 分享卡 / 打印不带底纹。完整条款见 VIS §3.10。
