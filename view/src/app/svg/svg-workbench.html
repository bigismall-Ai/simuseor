工作台说明

源码真值 canonical 是唯一可编辑文本；规范化只改排版/数值，优化只做语义等价清洗（内联 CSS、清元数据、去空容器），都不合并 path、不改 id。

语义部件 id 负责寻址，data-role / data-label / synonyms 负责阅读；点部件 id 后再画，形状会落进该组。

批量与校验 四档模式：仅规范化 / 仅稳定 id / 规范化+优化 / 优化+稳定 id；每行做渲染差异校验，有强差异的不进 ZIP。

LLM 闭环 提示词带部件、同义词与锁定项；补丁只接受定点 op（含 moveAnchor / setGradient / group），不整文件重写。

预览边界 当前预览作用于本地可信资产；外部文件先 sanitize，未进 sandbox。

落盘 页面不写磁盘；下载写回包后运行 scripts/svg_writeback.py（CRC 校验 + .bak / .bak.1）。
