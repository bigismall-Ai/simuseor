# shot_orbit · 环绕镜

> 环绕镜 · 匀角速度绕主体转圈，半径恒定

## 叙事（可改 `narrative.json`）

- 角色：一个成年男性，短深色头发，黑色夹克、黑色T恤、黑色长裤、黑色帆布鞋
- 场景：城市街道，两侧红砖建筑、行道树和路边停放车辆，路面有标线，暖色日光，前景空旷无人
- 风格：写实电影感，暖色自然日光，低饱和
- 时间线：

  - 0.0–5.0s：主体沿街道匀速行走；镜头绕主体转圈，主体始终在画内。
